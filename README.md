# Repères 3M – lot 2

Appli de terrain (PWA) pour la vérification des repères géodésiques et de nivellement IGN du lot 2
(Ouest et Sud) de Montpellier Méditerranée Métropole.

Installation : ouvrir le lien de l'appli dans Chrome (Android) ou Safari (iPhone), puis « Installer l'application » / « Sur l'écran d'accueil ».
